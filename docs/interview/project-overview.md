# Project overview

Triage Desk is for small teams that maintain public GitHub repositories and share triage duty. The planned MVP helps a Reviewer attach a next step to a report, a Member claim it, and the Reviewer see the private completion history even if GitHub still shows the issue as Open.

Slice 1 delivers verified sign-in and private workspaces. Slice 2 adds verified-email invitations and team access. Slice 3 adds public repository connections and manual import. Slice 4 connects Reviewer acceptance to Member self-claiming, progress, and completion.

For interviews, start with the two-account demonstration. It shows the visible workflow and the database-backed permission boundary in the same short scenario.
